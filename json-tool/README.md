# JSON 工具箱

纯前端 JSON 工具：格式化、压缩、校验、排序键、转义/去转义。

## 运行

Web Worker 需要通过 HTTP 访问（`file://` 下浏览器会拦截 Worker）：

```bash
cd json-tool
python3 -m http.server 8000
# 打开 http://localhost:8000
```

Worker 加载失败时自动降级为主线程模式，功能不变（大文件可能短暂卡顿）。

## 功能与边界

- **格式化 / 压缩 / 排序键**：自研解析器，数字保留原始字面量，大数字（如 `9007199254740993`、30 位整数）零精度损失。
- **校验**：非法 JSON 报出具体原因 + 行号 + 列号，可一键定位到输入框错误位置。
- **重复键**：与 `JSON.parse` 一致（保留最后一个值），并逐条警告重复键的位置。
- **BOM**：开头的 BOM 自动去除并提示；文本中间的 BOM 报非法字符。
- **嵌套深度**：上限 1000 层（验收要求 100 层），超限给出友好错误。
- **循环引用**：序列化器内置环检测，命中时提示"不是合法的 JSON"。
- **超长输入**：上限 100MB，超限友好报错；1MB JSON 格式化实测约 100–200ms。
- **历史记录**：IndexedDB 保存最近 10 次输入，点击即可恢复。

## 测试

```bash
node test.js   # 33 项验收测试
```

## 文件

- `worker.js` — JSON 引擎（解析/序列化/转义），Worker、主线程降级、Node 三端复用
- `main.js` — DOM 交互、Worker 调度、IndexedDB 历史
- `index.html` / `style.css` — 页面
- `test.js` — 验收测试
